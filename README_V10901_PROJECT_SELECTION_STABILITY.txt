TASNEEF V10901 - ثبات اختيار المشروع

المشكلة:
كان المشرف أو الفني يختار مشروعًا ثم تقوم إحدى عمليات إعادة تعبئة قوائم المشاريع بشكل غير متزامن بمسح الاختيار، فيظهر تنبيه "اختر المشروع" أو يضطر المستخدم لاختيار المشروع مرة أخرى بعد الدخول/الخروج أو رفع تذكرة.

الحل:
- حفظ اختيار المشروع لكل مستخدم ولكل حقل بشكل مستقل.
- استعادة الاختيار تلقائيًا بعد أي إعادة بناء لقائمة المشاريع، بشرط أن المشروع ما زال ضمن صلاحيات المستخدم.
- تثبيت اختيار مشروع المشرف قبل وأثناء وبعد عمليات الدخول والخروج والحفظ اليدوي.
- تثبيت مشروع تذكرة المشرف قبل وأثناء وبعد حفظ التذكرة.
- تثبيت مشروع تذكرة الفني قبل وأثناء وبعد حفظ التذكرة.
- زر مسح/تذكرة جديدة يمسح تفاصيل التذكرة فقط ولا يمسح المشروع المختار.
- لا يوجد polling أو تحديث دوري جديد.
- التخزين مربوط بمعرف المستخدم، فلا ينتقل اختيار مشرف إلى مشرف آخر على نفس الجهاز.
