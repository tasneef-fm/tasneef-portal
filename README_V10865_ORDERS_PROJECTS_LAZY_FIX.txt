TASNEEF V10865 — Orders Projects Lazy Loading Fix

المشكلة:
بعد V10864 كان فتح قسم الأوردرات يحمّل صفوف الأوردرات فقط، ولا يجدد مراجع المشاريع، لذلك قد تظهر قائمة المشروع فارغة في نموذج الأوردر أو الفلتر.

الإصلاح:
1) عند فتح قسم الأوردرات في الإدارة يتم تحميل جدول المشاريع أولاً.
2) بعدها يتم استدعاء OrdersUI.refresh() لتحديث projectOptions والفلاتر ثم الأوردرات.
3) تم إصلاح tasneefOrders10400.refresh ليكون تحديثاً كاملاً للمشاريع + الأوردرات بدلاً من تحميل الصفوف فقط.
4) نفس التصحيح مطبق على أوردرات المشرف مع بقاء المشاريع مقيدة بصلاحياته.
5) تم تغيير cache query في admin.html و supervisor.html لضمان تحميل JavaScript الجديد.

لا يوجد SQL جديد مطلوب لهذا الإصلاح.
