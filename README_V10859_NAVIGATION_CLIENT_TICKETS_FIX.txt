TASNEEF V10859 — إصلاح ثقل التنقل + تكتات بوابة العميل
=========================================================

المشاكل التي يعالجها هذا الإصدار:
1) ثقل/لاج عند التقليب بين قوائم الإدارة والمشرف والفني.
2) تكت بوابة العميل لا يظهر بعد الإرسال.
3) تكت العميل لا يصل للإدارة أو المشرف أو الفني.
4) منع رسالة نجاح وهمية عند فشل حفظ تكت العميل.

ما تم تغييره:
- إضافة Router نهائي سريع: tasneef_navigation_ticket_sync_v10859.js
  * يبدّل القائمة فوراً.
  * لا يستدعي refreshAll أو loadAll عند مجرد التنقل.
  * يرسم فقط القسم المفتوح.
  * التكتات تُعرض من الكاش فوراً ثم يتم تحديثها في الخلفية بدون تجميد القائمة.
- إضافة RPC موحد V10859 للتكتات.
- تكت العميل يُحفظ عن طريق Security Definer RPC ثم يتم التحقق من وجوده فعلياً في قاعدة البيانات.
- تكت العميل يحصل على رقم تكت ويرتبط تلقائياً بمشرف المشروع إن وجد.
- الفني يرى طابور التكتات الموحد، بما فيها تكتات العملاء الجديدة.
- بوابة العميل تعيد قراءة قائمة التكتات من المصدر الموحد V10859، بدون ربطها بتاريخ التقرير القديم.

خطوات التركيب بالترتيب:
-------------------------
1) ارفع جميع ملفات مجلد V10859 إلى السيرفر واستبدل الملفات القديمة.

2) افتح Supabase -> SQL Editor.

3) تأكد أنك سبق وشغلت هذه الملفات القديمة (مرة واحدة فقط):
   - supabase_supervisor_ticket_rls_v10852.sql
   - supabase_general_issues_creator_v10856.sql

4) شغّل الملف الجديد بالكامل:
   supabase_client_tickets_v10859.sql

5) في نهاية تشغيل SQL يجب أن تحصل على نتيجة JSON فيها:
   "ok": true
   "build": "V10859"
   "client_create_ready": true
   "client_list_ready": true
   "app_feed_ready": true

6) افتح reset-cache.html واضغط "تحديث الملفات الآن".

7) سجّل خروج ثم دخول من النظام.

اختبار التكت الصحيح:
--------------------
أ) افتح بوابة العميل من رابط مشروع فعلي.
ب) اضغط "رفع تذكرة" واكتب عنواناً واضحاً مثل:
   اختبار V10859
ج) بعد الإرسال يجب أن تظهر رسالة تحتوي على رقم التكت مثل T-1234.
د) يجب أن يظهر التكت مباشرة داخل تبويب التذاكر في بوابة العميل.
هـ) افتح الإدارة -> التكتات: يظهر نفس رقم التكت.
و) افتح حساب مشرف المشروع -> تذاكر: يظهر نفس التكت.
ز) افتح حساب فني -> التكتات: يظهر ضمن جميع التكتات.

مهم:
-----
إذا لم يتم تشغيل supabase_client_tickets_v10859.sql فلن يعطي النظام نجاحاً وهمياً؛
سيعرض رسالة الخطأ الحقيقية بدلاً من إخفاء المشكلة.
