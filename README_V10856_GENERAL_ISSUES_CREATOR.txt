التعديلات:
1) إضافة مشروع مشترك باسم: مشاكل عامة.
   - يظهر في تذاكر الإدارة والمشرفين.
   - متاح لكل المشرفين حتى لو لم يكن ضمن توزيع النظام الموحد 4.
   - لا يدخل في الحضور أو التسجيلات اليومية أو الأوردرات أو التقارير التشغيلية للمشرف.
