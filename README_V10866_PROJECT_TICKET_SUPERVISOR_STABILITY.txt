TASNEEF V10866 — Project / Ticket / Supervisor Stability Fix

تم الحفاظ على نفس آلية النسخة V10865 مع إصلاحات محددة فقط:
1) مشاريع التكتات في الإدارة:
   - تحميل المشاريع النشطة حتى لو كان الحقل is_active في سجل قديم فارغاً، طالما الحالة ليست موقوف/منتهي/مؤرشف.
   - ثبات المشروع المختار عند التحديث التلقائي وعدم مسحه من القائمة كل دقيقة.

2) مشاريع المشرف:
   - الربط المباشر في سجل المشروع (supervisor_id / app_supervisor_id / current_supervisor_id / supervisor_employee_code / supervisor_name) أصبح المصدر الأول.
   - توزيع الشهر يستخدم كحل احتياطي للمشاريع القديمة التي لا يوجد فيها ربط مباشر.
   - allowed_project_ids يعتبر ضمن نطاق المشرف عند وجوده.
   - إذا تغير مشرف المشروع، الربط المباشر يمنع رجوع المشروع للمشرف القديم بسبب توزيع شهري قديم.

3) التكتات في صفحة المشرف:
   - قائمة المشاريع لا تتبدل بين مصدرين مختلفين أثناء التنقل والتحديث.
   - اختيار المشروع يبقى ثابتاً أثناء التحديث التلقائي إذا كان المشروع ما زال متاحاً.

لم يتم تغيير تصميم النظام أو بقية آلية الأقسام.
