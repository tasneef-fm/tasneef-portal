TASNEEF V10872 - ROOT SUPERVISOR PROJECT BINDING

الإصلاح الجذري:
1) عند ربط مشروع بمشرف من توزيع النظام الموحد، يتم الآن تحديث projects.supervisor_id مع monthly_distribution في نفس العملية.
2) توزيع المشرف الحالي يستطيع معالجة رابط project قديم مؤقتًا بدل إخفاء المشروع.
3) إصلاح روز النرجس ومكين 52 يكتب supervisor_id لفهد وحده أولًا؛ الحقول الاختيارية لا يمكنها إفشال التحديث الأساسي.
4) تم إبقاء سياسة التحديث: أول فتح، بعد الإضافة، وبعد الحذف فقط.
5) كل مشرف يرى مشاريعه فقط؛ لا يتم استخدام allowed_project_ids لتوسيع مشاريع المشرف في المصدر النهائي.
