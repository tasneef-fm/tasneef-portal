V10850 — إصلاح بيانات بوابة العميل

1) ارفع جميع ملفات النسخة إلى نفس مجلد الموقع واستبدل الملفات السابقة.
2) افتح Supabase > SQL Editor.
3) افتح الملف supabase_client_portal_v10850.sql وانسخ محتواه بالكامل ثم Run مرة واحدة.
4) افتح رابط العميل واضغط Ctrl + F5.

الإصلاح:
- عدم التوقف عند وصول تقارير أو تذاكر فقط.
- تحميل ساعات العمل والحضور والتذاكر وخدمات العقد والتقارير والتقييمات من المشروع نفسه.
- استخدام دالة RPC واحدة بصلاحية قراءة آمنة لصفحة العميل.
- استمرار المصادر القديمة كاحتياط دون مسح البيانات الصحيحة.
