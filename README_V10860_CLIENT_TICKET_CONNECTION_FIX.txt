TASNEEF V10860 — إصلاح اتصال تكت بوابة العميل

سبب الخطأ الذي ظهر في الصورة:
- client-report.html أنشأ Supabase في المتغير: const sb
- كود V10859 كان يفحص window.sb
- في بوابة العميل لم يكن window.sb معرفاً، لذلك كان الكود يعرض:
  "تعذر الاتصال بقاعدة البيانات"
  قبل إرسال أي طلب إلى Supabase.

الإصلاح V10860:
1) ربط اتصال Supabase الصحيح: window.sb = sb
2) جعل كود التكت يستخدم db() الذي يلتقط الاتصال الفعلي سواء من sb أو window.sb
3) الإبقاء على V10859 كمسار الحفظ الأساسي الموثق
4) إضافة fallback إلى V10857 فقط إذا كانت دالة V10859 غير موجودة في Supabase
5) إظهار رسالة أوضح إذا كان SQL V10859 لم يتم تشغيله

طريقة التركيب:
1) ارفع ملفات V10860 واستبدل النسخة السابقة.
2) إذا لم تكن شغلت supabase_client_tickets_v10859.sql من قبل، شغله في Supabase > SQL Editor.
3) افتح reset-cache.html ثم حدث الملفات وسجل خروج/دخول.
4) افتح بوابة العميل وارفع تكت تجريبي.
5) يجب أن تظهر رسالة نجاح تحتوي رقم التكت، ثم يظهر في بوابة العميل والإدارة والمشرف والفني.

مهم:
- إذا ظهرت رسالة "SQL V10859 غير مثبت على Supabase" فهذا يعني أن اتصال قاعدة البيانات أصبح يعمل، لكن ملف SQL يحتاج تشغيل.
