TASNEEF V10861 — إصلاح INVALID_CLIENT_PORTAL_TOKEN

المشكلة:
بوابة العميل تفتح بشكل طبيعي، لكن عند رفع التذكرة يظهر INVALID_CLIENT_PORTAL_TOKEN.
السبب أن بعض روابط العملاء القديمة تفتح بالمشروع فقط أو برمز قديم، بينما SQL السابق اشترط رمز التقرير الجديد عند الحفظ.

التركيب:
1) ارفع جميع ملفات هذه النسخة مكان الملفات الحالية.
2) Supabase > SQL Editor: شغّل supabase_client_tickets_v10861.sql كاملًا.
3) تأكد أن آخر نتيجة تعرض: ok=true و build=V10861.
4) افتح reset-cache.html ثم حدّث الملفات.
5) افتح نفس رابط العميل القديم بدون تغييره وارفع تذكرة اختبار.

النتيجة الصحيحة:
- تظهر رسالة نجاح مع رقم T-xxxx.
- تظهر التذكرة فورًا في تبويب التذاكر ببوابة العميل.
- تظهر في الإدارة والمشرف والفني عبر مسار التذاكر الموجود في V10859/V10860.

ملاحظة:
V10861 يحاول أولًا استخدام public_token الخاص بأحدث تقرير منشور للمشروع، ثم يدعم روابط البوابة القديمة المتوافقة مع project/project_id.
