TASNEEF V10864 - SECTION LAZY DATA
=================================

الهدف
-----
تقليل ضغط السيرفر واللاج ومنع تحميل كل بيانات النظام عند فتح الصفحة أو الانتقال بين الأقسام.

ما تم تعديله
------------
1) كل قسم يجلب بياناته عند فتحه فقط.
2) القسم المفتوح فقط يتم تحديثه تلقائياً كل 60 ثانية.
3) التكتات تستمر بتحديثها الخفيف أثناء فتح شاشة التكتات فقط.
4) أي استدعاء قديم لـ loadAll / refreshAll بعد الحفظ أصبح يحدث القسم الحالي فقط بدل إعادة تحميل النظام كاملًا.
5) تم إيقاف التحميل المسبق للأقسام المخفية، ومنها:
   - الأوردرات
   - الأوقات الشهرية
   - التوزيع
   - العقود والخدمات
   - النظام الموحد
   - حضور المشرف
   - بيانات مشاريع الفني
   - بيانات التوزيع السريع داخل قسم العمال
   - مركز صلاحيات المستخدمين
6) عند فشل طلب سيرفر لا يتم مسح البيانات الموجودة في الذاكرة.
7) التصدير فقط يسمح بالتحميل الكامل عند فتح قسم التصدير لأنه يحتاج بيانات مجمعة.
